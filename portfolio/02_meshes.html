Project Procedural Geometric Modeling

3D Graphics

Project Overview

Procedural Geometric Modeling is the second assignment in CS250 Computer Graphics II at DigiPen Institute of Technology. The goal was to implement run-time procedural mesh generation for six geometric primitives — Plane, Cube, Sphere, Torus, Cylinder, and Cone — using parametric equations and a shared stacks/slices tessellation model. Each mesh is normalized to unit dimensions ([-0.5, 0.5]) and supports adjustable LOD via ImGui sliders.

Tasks Completed

  • Procedural 3D Geometry Algorithms — Implemented runtime generation of six geometric primitives — Plane, Cube, Sphere, Torus, Cylinder, and Cone — using parametric equations and a shared stacks/slices tessellation model.
  • Multiple Rendering Modes — Built triangle fill, wireframe, and normal visualization as three independently switchable rendering modes.
  • Capped Geometry — Constructed circular end caps for Cylinder and Cone as triangle fans, handling correct CCW winding order for both the top and bottom caps.
  • Runtime LOD Control — Exposed Stacks and Slices as interactive sliders that rebuild the mesh in real time, allowing continuous adjustment of mesh density.
  • Partial Arc Rendering — Extended the Torus with start and end angle parameters to support rendering of partial arcs.

Reflection

Challenges

The top and bottom caps of Cylinder and Cone require opposite CCW winding directions depending on which side the camera views them from — getting this wrong causes the caps to be culled entirely with no visible error.

The wireframe conversion needed to handle two different index patterns in the same buffer: quad pairs from the main body and triangle fans from the caps, which cannot be processed with a single uniform loop.

Solutions

Used an isTop flag to swap the order of the two ring vertices in each triangle, flipping the winding direction for the bottom cap.

Processed the buffer in two passes — first consuming groups of six indices as quads, then falling back to groups of three for the remaining cap fan triangles.

Learnings

Winding order bugs are silent: incorrect caps disappear rather than rendering incorrectly, so visual testing alone is not enough to catch them.

Designing index buffers with a consistent structure from the start makes wireframe conversion and other post-processing significantly simpler.
